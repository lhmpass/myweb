当前状态：本目录已有一张实拍照片 tiananmen.jpg（夜景正面，来自 Wikimedia Commons，
作者 Rominica xyloto，许可证 CC BY-SA 4.0 —— 因此页面上会自动显示一行署名，这是许可要求，不能删）。

想换成别的照片：把新图丢进本目录、删掉旧的 tiananmen.jpg，刷新页面即可。

【文件名】
  · 用 node server.js 打开时：叫什么名字都行，含中文也可以
    （服务端会列出本目录图片，优先识别含 tiananmen / hero / 天安门 / 城楼 的文件名）
  · 直接双击 index.html 时：只能用下面这几个固定名字（浏览器无法列目录）
      tiananmen.jpg   （最省事，推荐）
      tiananmen.jpeg / tiananmen.png / tiananmen.webp
      hero.jpg / hero.png

【建议规格】
  · 横版，宽 ≥ 1600px，宽高比接近 16:9（首页背景区域约 1100×600）
  · 城楼主体居中或偏右，左侧留出较空的天空/广场，标题文字会压在左侧
  · 避免严重过曝、杂乱人群遮挡城楼、以及带他人水印的图

【生效方式】
  · 双击 index.html 也会生效（图片加载不受 file:// 限制）
  · 用 node server.js 打开 localhost:8790 同样生效
  · 没有这张图时，首页自动回退为 CSS 绘制的五星红旗旗面，不会破图

  比赛材料里有出处记录会更稳妥。
