# 戎归·智启 — 运行说明

面向退役复学大学生的 AI 成长服务平台（演示原型）。

## 一、两种启动方式

| 方式 | 命令 / 操作 | AI 来源 | 适用场景 |
|---|---|---|---|
| A 离线 | 双击 `index.html` | 内置核验知识库 | 答辩现场断网、给评委快速看界面 |
| B 在线 | `node server.js` → 浏览器开 `http://localhost:8790` | DeepSeek + 知识库兜底 | 日常开发、真实多轮对话演示 |

方式 B 不需要 `npm install`，只用 Node 内置模块（需 Node 18 及以上）。
两种方式的界面、任务管理、学习规划、足迹功能完全一致，差别只在 AI 回答引擎。

## 二、配置 DeepSeek Key（只做一次）

1. 打开本目录下的 `.env`，把第一行改成你的 Key：
   ```
   DEEPSEEK_API_KEY=sk-你的Key
   DEEPSEEK_MODEL=deepseek-chat
   ```
2. 保存即可，**不用重启服务**（服务端每次请求重新读取）。
3. 顶栏胶囊会从「离线知识库」变成「DeepSeek 在线」，表示已生效。

### Key 安全（务必遵守）

- Key 只存在于 `.env`，由本机 `server.js` 代持，**前端代码里没有任何 Key**。
- `.gitignore` 已忽略 `.env`，提交 GitHub / Gitee 前确认 `git status` 里没有它。
- 服务默认只监听 `127.0.0.1`，同网络其他设备无法访问，也不会替你消耗额度。
- 不要截图 `.env`、不要把 Key 写进答辩 PPT、不要发到群聊。
- 若 Key 曾泄露，到 DeepSeek 开放平台删除重建即可。

## 三、DeepSeek 接入范围

| 功能 | 说明 |
|---|---|
| AI 校园助手 | 服务端把知识库命中的条目作为参考注入系统提示词，模型须输出 JSON：正文 + 依据资料 + 咨询部门 + 是否可确认。回答带「DeepSeek」徽标与免责提示 |
| 多轮对话 | 前端保留最近 6 轮上下文一起发送 |
| AI 学习规划 | 「DeepSeek 生成」按钮：提交专业 / 已掌握技能 / 每周时长 / 总周数，返回阶段化任务（含检验方式），仍可勾选、改文字、确认后转任务 |
| 失败兜底 | 在线不可用 / 报错时，自动改用离线知识库，并在回答顶部写明失败原因 |

系统提示词里的三条红线（不编造政策、涉密拒答、不替用户做重大决定）写在 `server.js` 的 `SYSTEM_CHAT` 常量中，可按本校情况调整。

## 四、常见报错对照

| 现象 | 原因 | 处理 |
|---|---|---|
| 顶栏一直显示「离线知识库」 | 服务没起，或 Key 未填 | 运行 `node server.js`；检查 `.env` |
| 「Key 无效或已失效」 | Key 复制不全、已删除、多了空格 | 重新粘贴，注意别带引号和空格 |
| 「账户余额不足」 | 平台额度用尽 | 充值或改用离线模式演示 |
| 「请求过于频繁」 | 触发限流 | 稍等重试，答辩前先用离线模式录屏备份 |
| 端口占用启动失败 | 8790 被占 | `.env` 里改 `PORT=8791` |
| 浏览器直连报 CORS | 你直接 fetch 了 api.deepseek.com | 必须走 `server.js`，别改前端直连 |

## 五、目录结构

```

data.js      校园知识库 / 岗位技能库 / 学习路径 / 足迹栏目

```

## 七、首页背景素材（天安门照片）

首页背景按「有照片用照片、没照片用 CSS 旗面」自动切换，检测代码在 `app.js` 的 `initHeroBg()`。

放入照片：丢进 `img/` 目录即可，**刷新页面就生效**，不用改代码。

```
用 node server.js 打开 → 文件名随意（含中文），服务端自动列目录，优先识别 tiananmen / 天安门 / hero / 城楼
直接双击 index.html   → 需用固定名：img/tiananmen.jpg（或 .jpeg/.png/.webp、hero.jpg、hero.png）
```

要求：横版、宽 ≥ 1600px、宽高比接近 16:9；城楼主体居中偏右，左侧留较干净的天空或广场（标题压在左侧）；不要带他人水印。
`file://` 双击打开也能加载图片，不受浏览器本地脚本限制。

### 关于「为什么是夜景这张」

同批候选共 4 张，逐张目检后淘汰 3 张：一张 CC0 文件其实是**长安街骑行人群**（城楼未入镜，文件名
"Close to Tiananmen" 意为"天安门附近"，并非城楼照片）；一张是画像特写（无天空留白）；一张白天老照片
前景骑车人与车辆抢眼。最终这张城楼正面、画像标语红灯笼齐全、上半为黑天空正好可压标题文字。

### 抓取渠道实测记录（2026-11-19）

| 渠道 | 结果 |
|---|---|
| Commons API | ✅ 可用，用于检索候选文件与许可证 |
| `Special:FilePath/<文件名>?width=1920` | ✅ **可用**，会 302 跳到官方缩略图地址，绕开了直接访问 `upload.wikimedia.org` 的 429 限流 |
| `upload.wikimedia.org` 原路径直连 | ❌ 持续 429（沙箱与宿主机两条网络均如此） |
| Unsplash / Pexels / Pixabay / Flickr / Openverse | ❌ 401 / 403 / 429 / 不可达 |
| Bing 图片 | ⚠️ 可抓但 `site:` 过滤不生效，结果多为新闻机构与付费带水印图库，未采用 |
| 内置图像生成 | ❌ 该地标被内容安全策略拒绝（`retryable:false`），未采用 |

### 使用注意

天安门影像用于教学与竞赛展示一般没问题，但仍要注意《国旗法》相关规定：国旗及其图案不得用作商标、
专利外观设计和商业广告，使用中不得倒置或以其他方式有损尊严。若项目后续涉及商业化展览或周边制作，
建议改用不含国旗元素的建筑照片，或保留 CSS 绘制的抽象旗面方案。
